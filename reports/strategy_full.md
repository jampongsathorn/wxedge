## 6) ตรรกะการตัดสินใจ (pseudocode สำหรับเครื่อง/LLM)

```text
INPUT: city, date, now_local_hour
PRECHECK
  if city in {hong-kong, shenzhen}: SKIP
  if now_local_hour < 13: ใช้ day-ahead เท่านั้น (โหมดเฝ้าดู; ยังไม่เข้าไม้)

1. รวมสมาชิกโมเดล (3–4 แหล่งหลักพอ): v_i = forecast_i − bias_i        # bias fit ย้อนหลัง
2. mu = median(v_i)                                                    # มัธยฐาน ไม่ใช่ค่าเฉลี่ย
3. sigma = sigma_pooled(unit) ปรับด้วย model_spread ของวันนั้น          # กว้างขึ้นเมื่อโมเดลเห็นไม่ตรงกัน
   ถ้า now ≥ 13 และมี obs: mu ← ผสม(obs, พยากรณ์) น้ำหนัก 0.5 @14:00 → obs ล้วน ≥16:00
   ถ้า now ≥ 16: ใช้ max-so-far + การกระจายของ 'ส่วนที่เหลือ' จาก 30 วันย้อนหลังของเมืองนั้น
4. p(bin) = Gaussian(mu, sigma) ตัดที่ขอบ bin ทุก bin ของวันนั้น แล้ว normalize

DECISION (เวลา 16:00 เป็นหลัก)
  b* = argmax p(bin)
  if p(b*) ≥ 0.90 and 0.02 ≤ price(b*) ≤ 0.10  → BUY YES 1% ของทุน   # ไม้หลัก
  elif p(b*) ≥ 0.90 and 0.10 < price(b*) ≤ 0.25 → BUY YES 1%          # ไม้รอง
  for every other bin b:
      if price(b) ≥ 0.50 and price(b) − p(b) ≥ 0.30 → BUY NO 1%       # ฝั่งขาย
  (ไม้คม p ≥ 0.97 ที่ 15:00 ทำได้ถ้าต้องการเข้าเร็ว)

RISK
  จ่ายจริง = ราคา + slippage; ถ้า NO: จ่าย 1 − YES_bid (ต้องดู bid จริง ไม่ใช่ last trade)
  เพดานรวม: ≤ 6 ไม้/วัน · ≤ 5% ของทุน/วัน · หยุดเมื่อ drawdown > 15% ของทุน แล้วทบทวน
  ถือถึงเฉลย (ไม่ TP) · stop −25% ได้ตามใจ
LOG: city, date, hour, bin, p, price, stake, reason(หลัก/รอง/NO) → ทุกไม้
```

## 7) ข้อจำกัดที่ต้องรู้ก่อนใช้เงินจริง

1. **ราคาที่ใช้ทดสอบคือ last-trade รายชั่วโมง ไม่ใช่ ask ที่เราจะได้จริง** → ไม้ YES ต้องจ่าย ask (ผลจริงแย่ลงเล็กน้อย) และไม้ NO ต้องจ่าย `1 − YES_bid` (ผลจริงอาจแย่ลงมาก) ⇒ **ต้องเก็บ bid/ask จริงใน `cheap_live.py --log` ก่อนขยายฝั่ง NO**
2. ข้อมูล 85 วัน ฤดูเดียว (ก.ค.–ก.ย. 2026) ยังไม่ผ่านฤดูหนาวและวันที่อากาศแปรปรวนหนัก
3. n ของไม้คม (p≥0.97, ราคา ≤0.15) เล็ก (หลักสิบ) → CI กว้าง อย่าใช้เป็นไม้หลัก
4. ตลาดบางวันไม่มี bin ที่ราคาอยู่ในช่วง → ไม่มีไม้ (นั่นคือพฤติกรรมที่ถูก: ไม่บังคับไม้)
5. ค่าธรรมเนียมสัญญาจริงบน Polymarket = 0 (แต่มี spread) → ที่ใส่ 2%+2 ticks คือ stress test
6. **เพดานสภาพคล่อง (สำคัญมากกับไม้ราคาถูก):** ไม้ที่ราคา 0.03 ให้ตัวคูณ ~33× → ต้องจำกัด `ขนาดไม้ × (1/ราคา) ≤ 5% ของปริมาณซื้อขายจริงของ bin นั้น` และไม่ควรจ่ายเกิน ~2% ของ volume รายวันที่ราคานั้น » ไม้ 1% ของทุนต่อไม้ที่ระบุในตารางสมมติว่าได้ fill ที่ราคาที่เห็น
7. 85 วัน ฤดูเดียว และผลตอบแทนที่สูงมาก (ROI หลักร้อย %) คือ *paper* — ตลาดจริงจ่ายช้ากว่า/ราคาใหม่ไวกว่า เมื่อมีคนอื่นใช้วิธีเดียวกัน (โพสต์เองก็บอกว่า edge ถูกบีบเมื่อคนเยอะ) ⇒ ควรวัดใหม่ทุกสัปดาห์ด้วย `cheap_live.py --log`
