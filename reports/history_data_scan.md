# Scan: ข้อมูลย้อนหลังก่อน 25 ก.ย. — มีอะไรจริงบ้าง (26 ก.ย. 2026)

คำถามจากผู้ใช้: "ย้อนหลังก่อน 25 ก.ย. — ก่อนนั้นมีแค่ last-trade จาก CLOB prices-history ใช่ไหม มีมั้ย? คนอื่นทำได้มั้ย"
วิธี: ทดสอบ API จริงทั้งหมด ณ 26 ก.ย. 2026 (ไม่เดา) — ตาม skill `agentic-code-workflow` ขั้น Scan (หาข้อเท็จจริงก่อน)

## คำตอบสั้น

| ชนิดข้อมูล | มีไหม (ย้อนหลังก่อน 25 ก.ย.) | ที่มา | ต้องมี key? |
|---|---|---|---|
| **ดีลจริง (fills)**: ราคา + ขนาด + ฝั่ง BUY/SELL + เวลา + token | **มี** ครอบคลุมทั้งชีวิตทุกตลาด (ทดสอบย้อนถึง 19 ก.ค. 2026) | `https://data-api.polymarket.com/trades?market=<conditionId>&limit=500&offset=N` | ไม่ต้อง |
| **ราคาระดับนาที** (last trade ต่อนาที) | **มี** | `clob.polymarket.com/prices-history?market=<tokenId>&fidelity=1` | ไม่ต้อง |
| **สมุดคำสั่งย้อนหลัง (L2 bid/ask ladder)** | **ไม่มี** จาก Polymarket (ให้แค่สมุดปัจจุบัน) | ต้องซื้อจากบุคคลที่สาม (polymarketdata.co: มีตั้งแต่ ส.ค. 2025 — เสียเงิน · polyhistorical/polyorderbooks: มีแต่ตลาด crypto) | ต้อง |

**สรุป**: ที่เราเคยเชื่อว่า "ก่อน 25 ก.ย. มีแค่ last-trade รายชั่วโมง" — **ไม่จริงทั้งหมด** เราขาดแค่ *สมุดคำสั่ง* แต่ **ดีลจริง (fills)** ระดับดีล มีให้ย้อนหลังฟรีทั้งประวัติ และ **ใครก็ดึงได้** ด้วย endpoint เดียว (public ไม่ต้อง key) — สิ่งที่เราพลาดคือ *วิธีใช้ข้อมูล* ไม่ใช่ *การเข้าถึงข้อมูล*

## หลักฐานที่ทดสอบจริง

### 1. ดีลจริงของ bin ที่เราเดิมพัน (dallas 88-89°F · ตลาด 25 ก.ย. 2026)

- ทั้งชีวิตของ bin นี้: **353 ดีล** (YES 121 + NO 232) · ช่วง 23 ก.ย. 22:57Z → 26 ก.ย. 00:39Z
- เฉพาะ **YES token** ในหน้าต่าง 20:00–22:00Z (15:00–17:00 local = หน้าต่างเข้าไม้): มีแค่ **6 ดีล**

| เวลา (local) | ฝั่ง | ราคา | ขนาด |
|---|---|---|---|
| 15:14 | BUY | 0.0500 | 10.0 |
| 15:16 | BUY | 0.0600 | 5.4 |
| 15:22 | SELL | 0.0400 | 5.8 |
| 15:36 | BUY | 0.0700 | 35.0 |
| 15:42 | SELL | 0.0400 | 107.9 |
| 15:55 | BUY | 0.0100 | 20.0 |
| **16:00 (นาทีที่ระบบเรา "เข้าไม้" @ask 0.04 · depth $46.3)** | **ไม่มีดีลเลย** | — | — |

→ ราคา 0.04 ที่ระบบบันทึกตอน 16:00 เป็น **quote ค้างที่ไม่มีใครเทรดด้วย** · ตลาดเดินไปที่ 0.01 ตั้งแต่ 15:55 (หลังสถานีขึ้น 92°F เวลา 15:53)
→ นี่คือหลักฐานตรงว่า "ราคาที่ระบบเห็น ≠ ราคาที่เทรดได้" และข้อมูลที่ดีลจริงคือตัวชี้ขาด

### 2. การสุ่มทดสอบ 8 ไม้จาก backtest (ไม้ h=16 · p≥0.90 · ราคา 0.02–0.25)

วิธี: เอา **ดีล BUY จริงดีลแรกภายใน 20 นาทีหลังเวลาเข้า** มาเป็นราคาที่ "ซื้อได้จริง"

→ hit 87.9% / ROI +817% ในอดีต **คำนวณจากราคาที่ซื้อไม่ได้** — ต้อง rebuild ด้วยราคาดีลจริง

### 3. ความครอบคลุมย้อนหลัง (ทดสอบจริง)

- dallas 88-89°F (ก.ย.): 353 ดีล ตั้งแต่ตลาดเปิด
- nyc 69°F or below (20 ก.ค.): 7 ดีล (ตลาดเปิด 19 ก.ค. 01:07Z)
→ ตลาดอุณหภูมิรายวันเปิดล่วงหน้า 1–2 วัน และ **ดีลทั้งหมดถูกเก็บไว้ครบ** ไม่มีอะไรหาย

### 4. "คนอื่นทำได้มั้ย" — ได้ทั้งหมด

- endpoint สาธารณะ ไม่ต้อง API key ไม่ต้อง login · ใครก็รัน query เดียวได้ผลเหมือนกัน
- ข้อจำกัด: `market=` ต้องใช้ **conditionId** (ไม่ใช่ token), ไม่มีตัวกรองเวลา (ต้องไล่ `offset` เอง), เรตจำกัดไม่ชัด → ควรเว้นจังหวะ
- ถ้าต้องการ *สมุดคำสั่ง* ย้อนหลัง (ไม่ใช่ดีล) ต้องซื้อ (polymarketdata.co มีตั้งแต่ ส.ค. 2025) — สำหรับตลาด crypto เท่านั้นที่มีบริการฟรี (polyhistorical, polyorderbooks)
