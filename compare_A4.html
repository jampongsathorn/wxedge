4 · คำตอบ + วิธีใช้ (กติกาที่ผลทดสอบรองรับ)

  • ของเรา (wxedge) ดีสุดโดยรวม — 50.9% day-ahead (สูงกว่าที่ดีสุดของ repo 5.4 จุด) และ 88.8% ระหว่างวัน (สูงกว่า floor 11.5 จุด) และ ROI +493% vs +24%
  • ถ้าจะลอกไอเดียจาก 3 repos → ลอก PolyWeather (hard floor, ทำได้ใน 20 บรรทัด, +39.7 จุด) รองลงมา weatherbot (bias รายแหล่ง + กติกาออกครบ)
  • polyBot ไม่มีอะไรให้ลอก — ไม่มีหลักฐาน, σ ตายตัว, แหล่งเดียว
  • ตัวขับเคลื่อนจริงมีแค่ 2 อย่าง: (ก) หัก bias รายโมเดล (+17.4 จุด) (ข) ใช้ข้อมูลหลัง peak (+52 จุด)
  1. รอ 15:00–17:00 ตามเวลาท้องถิ่นของสถานี (16:00 คุ้มสุด) — ห้ามทายก่อน 14:00
  2. ใช้ max ที่วัดได้ + การกระจายตัวของส่วนที่ยังเพิ่มได้ → p ต่อ bin
  3. ซื้อเฉพาะ ask 0.02–0.25 ที่ p ≥ 0.90 (หรือ ≥0.35 ถ้ารับเสี่ยงได้) · ask < 0.02 ห้ามซื้อ (ชนะแค่ 6%)
  4. ขนาด 1–2% ทุน/ไม้ · ~4 ไม้/วัน · รวม ≤10%
  5. ถือถึงวันปิด · stop-loss −25% ได้ · ห้าม take-profit (วัดแล้วลด ROI)
  6. obs ต้องเป็น IEM METAR รายชั่วโมง (ตรงตลาด 94%) — ห้ามใช้ NWS 5-min (56%)
